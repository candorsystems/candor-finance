# Candor Finance for OpenClaw

This is the official CLI-backed Candor skill package for OpenClaw. Publish this
package's `skills/candor-finance/` subtree as `candor-finance` on
ClawHub. That scoped MIT-0 subtree installs the `candor-finance` skill and
operates through the public `candor` executable. Do not publish this parent
directory or its proprietary adapter metadata.

Subscription setup and administration stay in the private Candor web control
plane. Support: https://candor.money/support
