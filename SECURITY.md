# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities in this package or the Candor service to
security@candor.money. Please do not open a public issue.

Please include:

- a concise description of the issue;
- affected URLs, commands, routes, or components;
- reproduction steps;
- potential impact; and
- whether you accessed any real user data.

Do not access, modify, delete, export, or disclose another user's data. Do not
perform denial-of-service testing, social engineering, spam, physical attacks,
or destructive testing. This is not a public bug bounty program.

## Supported versions

Only the latest released version of this package is supported. The package
connects to Candor's hosted MCP server at https://api.candor.money/mcp, which Candor
operates and patches directly.

The full policy, including trust boundaries and data custody, is at
https://candor.money/security.
